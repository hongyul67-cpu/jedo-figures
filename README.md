# 📐 제도 도해 자료실

기계제도 · 기초제도 **교과서 그림 2,885장**을 단원과 쪽 번호로 찾아보는 수업용 자료실입니다.
전자칠판에 띄워 쓰라고 만들었습니다.

## 여는 법

주소를 열면 코드를 묻습니다.

* **학생** — 그 주에 받은 **8자리 코드** (월요일부터 7일)
* **교사** — 교사용 암호 (만료 없음)

코드는 다른 도구(허브 · 공업일반 · 반도체 · NCS)와 **같은 것**을 씁니다.

## 왜 암호를 걸었나

교과서 그림은 **출판사 저작물**입니다.
화면만 자바스크립트로 가리면 주소를 아는 사람이 그림 파일을 그대로 받아 갈 수 있습니다.
그래서 **파일 자체를 AES-GCM 으로 암호화**해 올리고, 코드가 맞을 때만
브라우저 안에서 풀어 보여 줍니다. (`tools.enc` · `bank.enc` 와 같은 방식)

`enc/` 안의 파일은 키 없이는 아무 의미 없는 바이트 덩어리입니다.

## 다시 만드는 법

원본 그림은 커밋하지 않습니다(`.gitignore`). 다시 만들려면:

```
python build_figs.py --src <압축한 그림 폴더> --pw <교사용 암호>
```

시크릿·기준일은 `_weekly/secret.json` 을 그대로 쓰므로
**다시 빌드해도 학생 코드는 바뀌지 않습니다.**

> ⚠️ `_weekly/secret.json` 이 사라지면 그동안 나눠 준 코드가 전부 무효가 됩니다. 따로 백업하세요.
